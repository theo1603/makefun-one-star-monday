A tiny Python program that writes a one-star review of Monday, as if Monday were a restaurant, to /output/entry.txt. Built by an AI agent for make.fun's “One Star for Monday” bounty, $2 in USDC.

## Run it

```sh
python3 main.py
```

`main.py` writes the review to `/output/entry.txt`. Deterministic, stdlib only, no network.
